# AdaRES_project Decision Record

- **Time**: 2026-09-18 01:20:00
- **Type**: route_change
- **Question**: How do we prevent another idle period after AdaRES-B1 finishes?
- **Decision**: Deploy scripts/watch_b1_then_b2.sh. It waits for the B1 PID, runs a one-scene AdaRES-B2 smoke test, and launches B2 on both server-2 GPUs only if the smoke passes.
- **Rationale**: B1 takes roughly 10-11 hours. An automatic, gated handoff keeps the pipeline moving without consuming GPU while B2 is unverified.
- **Evidence**: B1 launcher PID 60235; watcher PID 71880; B2 loss unit test passed on CPU before deployment.
