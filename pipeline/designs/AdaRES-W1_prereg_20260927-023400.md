# AdaRES-W1: Cross-layer mask recoverability (preregistered)

2026-09-27 02:34 Asia/Shanghai. Read-only B4-E30 diagnosis on the first 64
ScanRefer training scenes, with augmentation disabled. No validation decisions.

Hypothesis: a materially better target mask is already present in the
penultimate decoder output, but final refinement destroys its geometry. This is
distinct from P2, which only swapped the confidence head while keeping final
masks, and E1, which measured within-query mask stability on validation.

For expression e, define O_l(e) = max_q IoU(M_lq, Y_e), with the same 0.5 mask
threshold and GT used only to diagnose candidate availability. A recoverable
case has O_(L-1) > O_L + 0.05. Match each prior mask to the final mask with
greatest binary IoU, independent of Y_e; among recoverable cases count those
whose matched final mask loses >0.05 IoU. Compare with same-index degradation
as an order-sensitive control. Also count final-selected query degradation,
which is observable at inference only in proxy form.

Expected direction: nontrivial recoverability AND matched degradation, rather
than merely different query indices. Repeated deterministic forward passes must
agree. If recoverability is rare or matched masks retain quality, reject the
proposed refinement bottleneck. Even a positive result establishes an oracle
availability gap only: a separate inference-valid preservation rule, paired
intervention/control and native backward/resources are mandatory for admission.
Do not simply choose the better layer using GT or scan layer weights on
validation. No model, config, queue entry or training is authorized by this
diagnostic.
