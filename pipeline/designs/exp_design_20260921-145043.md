## 3. AdaRES-B4 Mechanism
  - For each query, soft predicted-mask area and pairwise intersection define
    a differentiable soft-IoU matrix over all queries in the same sample.
  - Each query receives a normalized competition context containing the query
    latents of its overlapping alternatives.
  - The indicator head consumes the query, competition context, residual
    query-minus-context, and maximum overlap.
  - The path has no scalar gate or validation-selected parameter.
  - B1's hard positive/negative indicator supervision is unchanged.

## 4. AdaRES-B5 Mechanism
  - Layer-normalized query and phrase-token states are projected and unit
    normalized.
  - A no-temperature cosine similarity computes query-to-token compatibility.
  - Valid tokens form an attention distribution; the indicator consumes the
    query, grounded token vector, multiplicative interaction, and maximum token
    similarity.
  - Padded tokens receive -infinity before softmax and cannot affect output.
  - B1's indicator supervision and all decoder losses remain unchanged.

## 5. Controls And Falsification
  - B1 and B2 are fixed historical controls with identical data and schedule.
  - B4 includes the query residual path and ignores padded superpoints; failure
    would reject this explicit pairwise-competition formulation, not all
    set-aware ranking.
  - B5 includes the query residual path and ignores padded text tokens; failure
    would reject this direct token-evidence formulation, not all semantic
    alignment.
  - B4 and B5 do not import each other's model or loss code.
