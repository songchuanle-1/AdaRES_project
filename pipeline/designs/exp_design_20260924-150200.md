## 4. Experiment Plan
| ID | Config | Structural hypothesis | Control | Success criterion |
|---|---|---|---|---|
| AdaRES-F4 | configs_song/model_paper5/adares_f4_mask_reanchor_res.yaml | Reanchor layer i>0 fine/query attention using previous mask soft centroid | B4-E30, same fresh 30-epoch protocol | mIoU > 0.5094; target 0.5150 |

For valid superpoints v, query q and previous layer i-1:

```
p(q,v) = sigmoid(mask_logit(i-1,q,v)) * valid(v)
c(i,q) = sum_v p(q,v) * xyz(v) / max(sum_v p(q,v), eps)
a(i,q) = c(i,q) if any valid mask_logit(i-1,q,v)>0 else seed_xyz(q)
N(i,q) = topk_nearest(a(i,q), fine_xyz, k_i)
```

At i=0 use seed_xyz. The center calculation is stop-gradient; task-loss
gradients still reach the decoder through sampled attention values and all
original paths. No oracle masks or labels enter the anchor.
