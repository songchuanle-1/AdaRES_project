## 3. Analysis & Direction
C1/C2 did not improve B4 using auxiliary ranking objectives. G1 changes
the base indicator supervision itself: for each query i, detached
u_i = max_t IoU(1[sigmoid(M_i)>=0.5], Y_t), with Y_t training-object mask.
Train the two-class indicator toward (1-u_i,u_i) using the existing indicator
loss weight and eos coefficient; stop gradient through u_i. Other losses,
decoder, backbone, sampling, and protocol remain B4-identical.

available; do not claim significance if intervals cross zero. Flag a
material subgroup harm only if scene-clustered interval is entirely below
zero for a predeclared subgroup (unique/multiple object expressions);
otherwise report inconclusive. An empirical evaluation noise floor is not
yet available and must not be invented. The 16-scene pretrain subset is
diagnostic only, not a model-selection set.

## 7. Risk Assessment
The detached target is nonstationary as masks improve; broad soft labels may
reduce discrimination. The same eos and loss weight are retained without
validation search. The 16-scene mismatch is observational. B4-E30 is a
continuation, not a separately fresh matched control. Training and
worst-case memory remain unknown until launch.

## 8. Smell Check
The change replaces the supervision graph's source from sampled seed
membership to mask/target intersection and union, not a scalar setting or
renamed C1/C2. Both matched training and a later trained control are needed
to test its causal hypothesis. No novelty claim is made.
