# AdaRES-W2: Point-mass competition (preregistered)

2026-09-27 02:45 Asia/Shanghai. B4-E30 best checkpoint, first 64
ScanRefer training scenes, inference without augmentation. No validation search.

B4 computes query competition from soft mask IoU with each superpoint receiving
unit weight, whereas the reported mask IoU is over points. W2 asks whether
nonuniform superpoint sizes distort the rival context. Let n_s be the number
of points assigned to superpoint s. For mask probabilities p_qs define
I(q,r;n)=sum_s n_s p_qs p_rs and
U(q,r;n)=sum_s n_s(p_qs+p_rs-p_qs p_rs).
Use I/U in the existing B4 normalized overlap and trained indicator head.
The output masks and query vectors stay fixed. The matched control cyclically
rotates the same count vector, preserving distribution and total mass while
breaking correspondence to superpoint content. Original uniform B4 is anchor.

Predeclared reads: variation of n_s, count of material selection errors with
improved oracle-vs-selected confidence margin, matched shifted-count count,
fixed-rule point mIoU, flip count and repeat determinism. A useful mechanism
needs nontrivial count variability, reproducible head response distinct from
the shifted control and no unexplained wholesale harm. If count-weighting is
no better than the control or severely degrades fixed-rule mIoU, reject this
realization without weight scans. Even a positive frozen intervention would
require a candidate-specific native backward, resource comparison, independent
package/config and all six gates before queue admission. Labels are used only
to audit results, never to construct n_s or inference confidence.
