# Bugfix: checkpoint profiler eval chaining

- **Time**: 2026-09-20 09:50:00
- **Experiment**: AdaRES fixed checkpoint profiling protocol
- **Error type**: Python API contract
- **Error log summary**:
  ```
  AttributeError: 'NoneType' object has no attribute 'load_state_dict'
  ```
- **Root cause**: `IPDN.train()` is overridden without returning `self`, so
  chaining `model.cuda().eval()` assigns `None` to `model`.
- **Fix**:
  ```diff
  - model = model_module.IPDN(**cfg.model).cuda().eval()
  + model = model_module.IPDN(**cfg.model)
  + model = model.cuda()
  + model.eval()
  ```
- **Retry 1 result**: model construction passed, then strict checkpoint loading
  rejected two legacy RoBERTa buffers:
  `text_encoder.embeddings.position_ids` and
  `text_encoder.embeddings.token_type_ids`.
- **Compatibility fix**: allow only those two known non-parameter buffers as
  unexpected keys. Any missing key or any other unexpected key remains fatal.
- **Retry 2 result**: fixed. The same B1 4-scene protocol completed on
  server-2 GPU1 with 108 expressions.
- **Verified outputs**:
  - Effective active queries: 22.277 +/- 10.106
  - Mean latency: 25.773 ms per expression
  - Median latency: 13.884 ms per expression
  - Peak allocated CUDA memory: 2161.027 MiB
  - Pilot subset mIoU: 0.311 (not a replacement for full-validation mIoU)
- **Final status**: fixed and admitted for uniform B1/B2/B3 checkpoint
  profiling.
