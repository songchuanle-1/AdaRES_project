# Bugfix: checkpoint profiler eval chaining

- **Time**: 2026-09-20 09:50:00
- **Experiment**: AdaRES fixed checkpoint profiling protocol
- **Error type**: Python API contract
- **Error log summary**:
  ```
  AttributeError: 'NoneType' object has no attribute 'load_state_dict'
  ```
- **Root cause**: `IPDN.train()` is overridden without returning `self`, so
  chaining `model.cuda().eval()` assigns `None` to `model`.
- **Fix**:
  ```diff
  - model = model_module.IPDN(**cfg.model).cuda().eval()
  + model = model_module.IPDN(**cfg.model)
  + model = model.cuda()
  + model.eval()
  ```
- **Retry**: attempt 1, pending verification on the same B1 4-scene profile.
