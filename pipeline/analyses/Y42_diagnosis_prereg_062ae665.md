# AdaRES-Y42: cross-channel point covariance diagnosis

Owner tick: 062ae665ba824deba180a65efb4c44cf.
Scope: AdaRES_project only; phase 1; W2 remains scientific comparator.

## Hypothesis
Superpoint means and channelwise point variances do not determine the joint
point-feature distribution. Equal native means, diagonal variances, point
counts, centroids, queries and masks can conceal different cross-channel
co-occurrence. A full-channel covariance confidence path could expose that
missing evidence without changing the native mask candidate set.

## Matched Control
Construct paired point features with equal means and diagonal population
variances in every channel but opposite cross-channel correlation. Hold all
superpoint features, query, coordinates, masks and point incidence fixed.
Execute the actual W2 and Y39 confidence classes, not proxy formulas.
Measure baseline and Y39 response, covariance separation, point permutation
invariance and independent-repeat noise. Use all native channels, no selected
feature subset, covariance temperature, neighborhood radius or numeric sweep.

## First Discriminating Test
Inspect only the relevant W2/Y39 extraction and readout dependencies. Run a
CPU actual-class paired intervention with frozen seed 1999 and 32 independent
synthetic cases. If existing Y39 distinguishes the covariance-only pair above
repeat noise, reject the missing-realization premise. If invariants fail,
repair and retain the failed evidence. A separating descriptor is diagnosis,
not evidence of native necessity or trained efficacy.

## Native Gates If Diagnosis Survives
Prediction-blind native TRAIN incidence and actual same-checkpoint controls;
correct versus rolled descriptors; original train path forward/backward,
disabled-path equality, all new tensor gradients and finite loss; fresh
authorized GPU1 resource checks; independent physical package/config; current
goal constraints and original seed/30-epoch protocol. No gate is passed here.
Freeze full 9508-expression/141-scene Y42/W2/B1 twice each, FIRST primary,
whole-scene bootstrap 10000 seed 1999, TRAIN-only subgroup cutoffs 1487/3325,
subgroup harm and trained paired cost before any eventual admission.

## Limits
This preregistration makes no novelty, necessity, generalization, target,
lightweight Pareto or efficacy claim. Conceptual proximity to Y39 is not a
rejection criterion; the above actual intervention is.
