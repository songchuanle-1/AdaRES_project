# Y48 Native Matched-Indicator Mask Exchangeability Diagnosis

- Stable ID AdaRES-Y48; hypothesis_id native-matched-mask-exchangeability.
- Hypothesis, not fact: a single native matched-query indicator label may
  assign conflicting confidence targets to candidates with exactly identical
  final hard masks. If such cases occur in the frozen prediction-blind TRAIN
  cohort, an equivalence-aware target could remove confidence suppression
  caused by arbitrary winner identity without changing the inference selector.
- This concerns ownership labels on identical output masks, not pairwise
  overlap information (rejected Y47), relative ranking loss (rejected Y29),
  point-confusion categorical supervision (training Y45), or within-mask
  spatial components (blocked Y46). No structural independence/novelty claim
  until actual native and relevant closed implementation audits.
- First audit the actual W2 indicator loss and matching-target construction.
  Execute that exact loss on fixed, indistinguishable query/mask duplicates,
  with unchanged native matching assignments, correct/wrong/equal-target
  controls and gradients. If labels already respect equivalence, retain that
  disconfirming result and reject this missing-realization premise.
- Native incidence uses all32 previously frozen TRAIN expressions/128queries.
  Read cached arrays programmatically, never dump them. Group exact final hard
  mask bitsets at the inherited mask sign, including empty groups in counts;
  do not alter thresholds, cluster nearly equal masks, select scenes or tune.
  Empty-mask duplicates alone do not support useful positive-target diagnosis.
- Conditional target closure is diagnostic only: native positive assignment
  expanded to its exact identical-mask class, all other labels unchanged.
  Unchanged parent loss/selector/weights, no new margin, temperature or epoch
  setting. Check source duplication before any implementation/admission.
- Lack of native matching labels or useful positive nonempty duplicates
  remains a diagnosis gap, not a gate PASS or efficacy claim. Synthetic label
  ambiguity does not establish an actual bottleneck or trained benefit.
- Any admission requires actual native backward/controls/resources/physical
  independence/goal review, releasedSPFormer/seed1999/fixed30/singleGPU and the
  unchanged full9508/141 twice EACH/FIRST/W2+B1/scene+subgroup harm/cost plan.
