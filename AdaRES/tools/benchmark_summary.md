## 5. 结论

1. **base 和 base+1 推理速度一致**（差值 0.9%，在噪声范围），两者代码/yaml model 部分完全相同
2. **base+3** (`cf12_4_1_5_0`) 比 base 慢 ~3%，有微妙差异
3. **base+2** (`cf12_4_1_11_0`) 慢 10.8%，但 CUDA 显存更低（~2185 MB），mIoU 为 502，性价比好
4. **精度优先**：`cf12_4_0` (514 mIoU) 比最快慢 13.9%
5. **RSS 峰值**所有变体均在 4942~5023 MB，差异 < 2%，模型结构对 CPU 内存影响极小
